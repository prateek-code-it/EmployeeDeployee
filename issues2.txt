1. Role-Based Access Control & User Management

    Super Admin Role: Decouple from individual companies to manage platform-level configurations and multi-tenant oversight.

    User Provisioning: Allow Company Head, Admin, and HR roles to create and manage user accounts.

    Employee Code Generation: Automatically generate structured Employee Codes to serve as unique usernames for login (Format: [Company Code]-[Post/Designation Code]-[Serial No]).

    Authentication: Provide secure login credentials (User ID/Employee Code + Password) along with mandatory email address mapping in employee profile records.

    Role & Designation Hierarchy: Support extensible roles and designations during onboarding (e.g., HR Head/Assistant, Purchaser/Store Manager, Safety Engineer, Executive Engineer, Quality Engineer, Civil/Mechanical/Electrical Site Engineers).

2. Employee Self-Service (ESS) Portal

    Profile Management: Allow employees to self-manage personal details, bank account information, and essential credentials.

    Leave Management: Provide automated leave application, tracking, and balance management.

    Company Noticeboard: Display global circulars, notices, and announcements uploaded by Admins or Company Heads directly on every user's dashboard.

3. Vendor & Procurement Management

    Vendor Selection Control: Restrict sales and procurement selections to pre-approved vendor and purchaser master records only.

4. Project Master & Resource Allocation

    Project Information Schema:

        Project Name

        Client Name

        Tender / Work Order (WO) Reference

        Work Order Value

        Scope / Project Description

    Resource Allocation: Enable multi-project assignment for employees with an automated warning prompt whenever an already-assigned employee is allocated to a new project.

    Team Summary: Display role-wise resource summaries directly within the project overview dashboard.

5. Project Document Management System (DMS)

    Default Document Categories:

        Work Order

        BOQ / SOQR & Technical Specifications

        Running Account (RA) Bills

        Test & Quality Reports

        Architectural / Engineering Drawings

        Daily Progress Reports (DPR)

        Inward / Outward Correspondence (Letters Dispatched / Received)

    Custom Categories: Provide a searchable dropdown for document types with an Add New Document Type dynamic creation option.

    Access Control & Privacy: Implement granular sharing settings where newly uploaded documents remain private to the uploader by default unless explicitly shared with the team.

6. Daily Progress Report (DPR) Module

    Submission Role: Restrict DPR creation and submission strictly to designated Site Engineers.

    Field Updates:

        Remove the legacy Weather field.

        Manpower: Track Skilled and Unskilled labor counts.

        Material Tracking: Record Material Received (Qty) and Material Required (Qty).

        Planning: Add a dedicated section for Next Day Planning.

    Analytics & Filters: Enable date-range filtering to generate and view project-specific DPR histories.
